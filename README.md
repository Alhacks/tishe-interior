# ТИШЕ — лендинг студии дизайна интерьера

Портфолио-концепт для Кворка. Вымышленный бренд, демонстрационные проекты и цены. Фотографии Unsplash иллюстрируют визуальное направление и не являются работами студии.

Демонстрация: [открыть сайт «ТИШЕ»](https://alhacks.github.io/tishe-interior/).

Исходный код: [Alhacks/tishe-interior](https://github.com/Alhacks/tishe-interior).

## Что входит

- Адаптивный лендинг с отдельными композициями для компьютера и телефона.
- Галерея из трёх концепций: фильтры, подробности проекта в доступном диалоге.
- Три пакета услуг, калькулятор стоимости по площади и тарифу.
- Генерация и скачивание текстового брифа без передачи данных на сервер.
- Мобильное меню, FAQ, клавиатурная навигация и поддержка reduced motion.
- Метатеги, favicon и конфигурация Vercel.

## Локальный запуск

В каталоге проекта выполните:

```sh
python -m http.server 8000 --directory dist
```

Откройте http://localhost:8000. Установка зависимостей и сборка не требуются.

## Публикация на GitHub Pages

Для публикации с вашего компьютера установите Git и GitHub CLI. Распакуйте весь архив и запустите скрипт из папки проекта. Скрипт использует ваш аккаунт, создаёт публичный репозиторий, загружает файлы, включает Pages, дожидается публикации и печатает ссылку. Авторизация происходит в вашем браузере; пароль или токен передавать в чат не нужно.

Windows, из PowerShell в папке проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\publish-github.ps1
```

Параметр ExecutionPolicy действует только для этого запуска, системные настройки не меняются. Если Git или GitHub CLI не установлены, установите их и откройте терминал заново:

```powershell
winget install --id Git.Git --exact
winget install --id GitHub.cli --exact
```

macOS или Linux:

```sh
bash publish-github.sh
```

На macOS с Homebrew зависимости устанавливаются командой `brew install git gh`. На Linux используйте инструкции https://cli.github.com/ для вашего дистрибутива.

Если репозиторий с таким именем уже существует, скрипт остановится до загрузки. Можно выбрать другое имя: `bash publish-github.sh tishe-portfolio` или добавить `-Repository tishe-portfolio` к команде Windows. Повторный запуск из той же папки обновляет созданный репозиторий без принудительной перезаписи истории.

### Публикация вручную

Загрузите проект в публичный репозиторий `tishe-interior`. В **Settings → Pages → Build and deployment → Source** выберите **GitHub Actions**. Workflow `.github/workflows/pages.yml` публикует каталог `dist` после каждого push в `main`. Первую публикацию можно запустить вручную в **Actions → Publish portfolio demo → Run workflow**.

Демонстрация будет доступна по адресу `https://<ваш-логин>.github.io/tishe-interior/`. Все пути к файлам относительные и поддерживают размещение в подкаталоге GitHub Pages.

## Альтернативная публикация на Vercel

В каталоге проекта:

```sh
npx vercel login
npx vercel --prod
```

Файл `vercel.json` уже задаёт статический каталог `dist`. В интерфейсе Vercel выберите Framework Preset **Other**, отключите Build Command и укажите Output Directory **dist**.

## Ограничения

Форма создаёт локальный файл и не отправляет заявку. Для настоящей студии нужно заменить бренд, проекты и тарифы, добавить реальные контакты и обработчик заявок. При публикации GitHub Actions запускает `download-assets.py`: скачивает исходные фотографии Unsplash и шрифты Google Fonts и размещает их вместе с сайтом. Посетителям не требуется соединение с этими сервисами. Скрипт также можно запустить локально для автономного размещения.
